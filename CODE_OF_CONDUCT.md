# Code of Conduct

samkhya adopts version 2.1 of the **Contributor Covenant** as its
community code of conduct. Read the full text here:

  https://www.contributor-covenant.org/version/2/1/code_of_conduct/

A short summary: contributors, maintainers, and anyone else
participating in this project — through issues, pull requests,
discussions, code review, or any other channel — agree to treat each
other with respect. Disagreement on technical decisions is welcome and
expected; personal attacks, demeaning language, and conduct that makes
participation hostile are not.

## Scope

This Code of Conduct applies in all project spaces (this repository,
its issue tracker, its pull-request review threads, any associated
chat) and when an individual is representing the project in public.

## Reporting

If you experience or witness behavior in a samkhya space that is
inconsistent with the Contributor Covenant, report it to the
maintainer via a private GitHub security advisory at:

  https://github.com/singhpratech/samkhya/security/advisories/new

Reports are read by the maintainer only and treated confidentially.
The maintainer will respond within a week of receipt.

## Enforcement

The maintainer follows the **Contributor Covenant v2.1 Enforcement
Guidelines** when responding to reports. The four-step ladder
(correction → warning → temporary ban → permanent ban) is documented
in the linked covenant text.
